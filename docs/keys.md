# Keys

What each key does in the bar, as the Keys topic (`?shortcuts`) shows it:

<!-- nodi:generated keys -->
| Key | What it does |
|---|---|
| Enter | Run the row; a second Enter where it asks |
| Ctrl Enter | Copy what the row holds |
| Ctrl K | The row's other actions; type to find one |
| Ctrl Shift F A D H | Favourite, alias, deeplink, hide the row |
| Ctrl Shift P | Pin a clipboard entry |
| Tab | Fill the row in, or ask your agent |
| Ctrl 1-9 | Run one of the first nine rows |
| Up Down Ctrl N P | Move in the list |
| PgUp PgDn | A page of the list |
| Shift Up Down | Scroll the pane beside the list |
| Shift PgUp PgDn | A page of the pane |
| Ctrl D U | Half a page of the pane, while one is up |
| Ctrl R | An earlier query, again; older on each press |
| Ctrl W | Delete the word before the cursor |
| Ctrl E F B | To the end, a letter on, a letter back |
| Esc | Close; a step back where there is one |
<!-- /nodi:generated -->

In the field, Ctrl+W, Ctrl+E, Ctrl+F and Ctrl+B edit as a shell does,
and Ctrl+A selects all. Holding Ctrl shows the digit that runs each of
the first nine rows.

With the mouse, a click runs a row, a right click opens its actions
(Ctrl+K's), and each key shown in the footer clicks.

Logging out, rebooting, shutting down, clearing a history and quitting a
process you did not name ask for a second Enter; a script filter's row
that asks shows the exact command it runs, and its risk, while it waits.
